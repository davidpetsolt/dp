Mode Logic
PShutter dial A + aperture A
AShutter dial A + aperture set to F-number
SShutter dial set + aperture A
MShutter dial set + aperture set to F-number
  • Not a traditional PASM dial — mode is determined by shutter dial + aperture tile together.
  • Aperture may be unavailable at the widest zoom. Zoom to ~28–35mm equivalent and retry.
    • Film Style Menu Path
  • Main Menu > JPG Settings > Film Style > Film Style Settings
  • Color profiles: Standard, Vivid, Natural. Mono profiles: Monochrome, Monochrome High Contrast.
  • Contrast, Highlight, Shadow, Sharpness, Saturation each range -2 to +2 — not ±3.
  • No Q button or tile-overlay interface on this camera, unlike Panasonic.
    • Noise Reduction & iDR
  • NR (JPG) is a Low/Medium/High scale, not a numeric value.
  • NR (Long Exposure) is a separate dark-frame-subtraction setting — leave On for JPG-only shooting.
  • iDR (Intelligent Dynamic Range) is its own setting, separate from NR. Off preserves shadow depth (used for Belgrade Fade); otherwise untested per preset.
  • No in-camera grain control exists. Grain is only available through the Leica LUX app's Leica Looks.
    • EV Cheat Sheet
  • Positive EV brightens, negative EV darkens and protects highlights.
  • Vivid: +0.3 · Retro indoors: -0.3 · Retro outdoors: -0.7 · Retro bright sun: -1.0
  • Belgrade Fade: -0.7 always — the underexposure is the look.
  • B&W Soft Calm: -0.3
    • LUX App (iPhone)
  • Approximating C2 requires P mode, not A mode, to access manual shutter speed.
  • Leica Looks in-app offer intensity and grain sliders only — no separate contrast/sharpness/saturation controls.
    • Bright-Sun C2 Recipe
  • EV -1.0, Auto ISO capped at 800, F11, ND8 filter in use.
    • Leica Photos App
  • Always assume latest app version.
  • Bluetooth is for pairing/wake only — photo transfer is over WiFi.
  • Prefer 5GHz WiFi. Selected import beats importing all. JPG-only transfer beats RAW.
    • Charging
  • USB-C PD preferred.
  • Slow flashing green = charging. Solid green = fully charged.
    • File Format
  • JPG only. Film Style adjustments (contrast, sharpness, saturation, highlight, shadow) bake directly into the image. No RAW fallback.
    • Fn Buttons
  • All Fn buttons remain at factory defaults. Nothing has been remapped.
